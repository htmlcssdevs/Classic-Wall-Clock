## ✨ Features

- Real-time analog clock display
- Smooth rotating hour, minute, and second hands
- Clean classic wall-clock styling
- Responsive and lightweight implementation
- Easy to customize colors, sizes, and layout

## 🚀 Run It Locally

```bash
git clone https://github.com/htmlcssdevs/Classic-Wall-Clock.git
cd Classic-Wall-Clock
open index.html
```

If you are using a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
